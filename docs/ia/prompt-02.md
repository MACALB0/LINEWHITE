Actúa como QA Automation Engineer experto en Jest y mocking de Node.js. La estrategia recibe usuario y contrasena, consulta PostgreSQL mediante pool.query, analiza res_respuesta, valida el hash con argon2.verify y devuelve un objeto con id, id_tipo_usuario, cedula, nombre y apellidos. Genera exactamente 8 pruebas Jest utilizando mocks para PostgreSQL, Argon2 y passport-local. Cubre usuario inexistente, usuario no autorizado, contraseña incorrecta, autenticación correcta, error de base de datos, serialización, deserialización correcta y error durante deserialización. No uses una base de datos real. Entrega código CommonJS compatible con Node.js.
